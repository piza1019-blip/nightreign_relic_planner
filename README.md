# ELDEN RING NIGHTREIGN 遺物・献器検索 試作品 v0.12

## 起動方法（Windows 11）
1. ZIPを展開します。
2. `nightreign_relic_planner` フォルダを開きます。
3. `start_app.bat` をダブルクリックします。
4. ブラウザで `http://localhost:8000` が開きます。

※ v0.12から固有遺物データは `unique_relics.json` から読み込みます。`index.html` を直接ダブルクリック（file://）してもブラウザの制限でJSONを読み込めないため、必ず `start_app.bat` から起動してください。Python 3 がインストールされている必要があります。

## 固有遺物データの編集方法
1. アプリを閉じる必要はありません（編集後にブラウザを再読み込みすればOK）。
2. `unique_relics.json` をメモ帳などで開きます。
3. 遺物データを追加・変更して保存します。
4. ブラウザで `Ctrl + R` を押して再読み込みします。

データはJSON形式です。各遺物は次の形式で記述します。

```json
{
  "name": "遺物名",
  "color": "red",
  "effects": ["効果1", "効果2"],
  "location": "入手場所",
  "vendor": "販売NPC（任意）",
  "price": 500,
  "unlock_condition": "販売条件（任意）"
}
```

色は `red`（赤）、`blue`（青）、`yellow`（黄）、`green`（緑）を指定します。`effects` は配列で、効果ごとに文字列を1つ入れます。

## 起動できない場合
- Python 3 が必要です。Windowsのコマンドプロンプトで `py --version` を実行して確認できます。
- `start_app.bat` 実行後に画面が閉じる場合は、Pythonが未インストールか、`py` コマンドが使えない可能性があります。
- その場合は Python 3 をインストールしてから再度実行してください。

## 収録データ
- 献器：74種類
- 固有遺物：74種類（既存44種類＋小壺商人のバザー追加30種類）
- 「薄汚れたフレーム」は重複登録せず、販売情報を追記。
- 同名でも効果が異なる販売品は別候補として登録。

## 機能
- 通常遺物・深層遺物の色別個数入力
- 通常出撃／深き夜の切り替え
- キャラクター別献器の絞り込み（共通献器は常に対象）
- 効果キーワードに一致する固有遺物を通常枠候補へ追加
- 「全」枠を含む最大配置数を探索してランキング表示
- 空き枠に入れられる色を表示

## 注意
- 固有遺物は入力した効果キーワードに一致したものだけを自動追加します。キーワードが空欄の場合、固有遺物は追加されません。
- データは提供された画像・テキストをもとに登録しており、ゲーム内での最終照合は未実施です。
- 入力内容は外部へ送信されません。
